# CreativeGroup データプラットフォーム — ポータル & グロースハック設計書

**作成日**: 2026-05-20
**担当**: Claude Code + CreativeGroup（yamaguchi）
**ステータス**: レビュー待ち

---

## 1. ビジョン・目的

CreativeGroupの全社データを一元管理し、グロースハックに必要な意思決定をリアルタイムで行える「データドリブン経営基盤」を構築する。

- 全ダッシュボード・ツールへの入口となるポータルを新設する
- グロースハックのPDCAサイクル（発見→決定→実行→検証）を1画面で完結させる
- Google OAuthによるロール別アクセス管理で、社内外の関係者が適切なデータにアクセスできる環境を整える

---

## 2. 決定事項サマリー

| 項目 | 決定内容 |
|------|---------|
| ハブ形式 | ポータル型（独立トップページ `/portal`） |
| アーキテクチャ | 段階的拡張（既存 Node.js + Express を活かす） |
| 認証方式 | Google OAuth 2.0（passport.js） |
| ロール数 | 5ロール |
| グロースハック形式 | 両方一体型（KPIファネル + ICEスコアリング + 施策管理） |
| リファレンス形式 | ポータル全体のガイドページ + インラインヘルプ（ツールチップ） |
| ダッシュボード拡張性 | 設定ファイルにカードを追加するだけで対応可能 |

## 3. 実装フェーズ

### Phase 0 — 土台（Google OAuth + ポータル）
既存ダッシュボードを権限付き構成に移行し、全機能への入口となるポータルを新設する。

- Google OAuth 2.0 実装（passport.js）
- ロール管理（`data/roles.json` にメール→ロールの対応を記載）
- ポータルページ新設（`public/portal.html`）
- 既存ダッシュボードの認証ミドルウェア適用
- ポータル全体リファレンスページ新設（`public/guide.html`）

### Phase 1 — グロースハックダッシュボード
KPIの発見から施策実行・検証まで1画面で回せるグロースハックツールを構築する。

- KPIサマリーカード（BigQuery連携）
- グロースファネル可視化（Acquisition → Revenue）
- ICEスコアリング × 施策管理CRUD
- 施策ステータス管理（アイデア / 計画中 / 実行中 / 完了）
- インラインヘルプ（各用語に「?」ツールチップ）
- 専用APIルート（`routes/growth.js`）

### Phase 2 — 広告ROAS ダッシュボード
Google Ads / Meta / TikTok / Yahoo! の広告データをBigQuery経由で横断分析する。

- 各広告媒体API → BigQuery 日次同期
- チャネル横断ROAS可視化
- 予算アロケーション画面

| 👑 オーナー | 経営者 | 全機能アクセス・編集・管理ツール |
| 💼 マネージャー | 部門長 | 全機能アクセス・編集・管理ツール |
| 🏢 社員 | 正社員 | 売上閲覧・グロース編集・広告閲覧・Pamun・Trepo閲覧 |
| 👤 スタッフ | アルバイト・インターン | 自チームの売上・グロース閲覧・自分のTrepoデータ |

### ロール付与の仕組み

`data/roles.json` にメールアドレスとロールを記載。Google OAuthログイン時にメールアドレスで照合し、セッションにロール情報を付与する。新メンバー追加はこのファイルへの1行追記のみ。

```json
{
  "yamaguchi@example.com": "owner",
  "manager@example.com": "manager",
  "staff@example.com": "staff"
}
```

## 5. ポータルページ設計（`/portal`）

### レイアウト

- **ヘッダー**: CG ロゴ・ログインユーザー名・ロールバッジ・ログアウト
- **挨拶エリア**: ユーザー名・日付・当日のサマリー数字（売上・実行中施策数）
- **カードグリッド（3カラム）**: ダッシュボードへのリンクカード
- **管理ツールエリア**: オーナー・マネージャーのみ表示

### カード仕様

各カードは `data/portal-cards.json` で管理。フィールド：

```json
{
  "id": "growth",
  "icon": "🚀",
  "title": "グロースハック",
  "description": "KPIファネル・ICEスコア・施策管理",
  "href": "/growth",
  "status": "active",
  "roles": ["owner", "manager", "employee", "staff"],
  "kpiKey": "activeInitiatives"
}
```

**新しいダッシュボードの追加**: `portal-cards.json` にエントリを追加するだけ。コード修正不要。

## 6. グロースハック画面設計（`/growth`）

### 3セクション構成

**① KPIサマリー（最上部）**
- 月次売上 / 新規案件数 / 継続率 / 広告ROAS / 施策実行中件数
- BigQueryから取得・前月比の増減表示

**② グロースファネル（左カラム）**
- Acquisition（認知）→ Interest（興味）→ Conversion（成約）→ Retention（継続）→ Revenue（売上）
- 各ステップの数値と転換率を表示
- ボトルネック（転換率が低いステップ）を自動検出してアラート表示

**③ 施策管理 × ICEスコア（右カラム）**
- 施策一覧テーブル（ICEスコアで自動ソート）
- 「＋ 施策を追加」ボタン → モーダルフォーム
- ステータス: アイデア / 計画中 / 実行中 / 完了
- 施策データは `data/initiatives.json` に永続化

### ICEスコア計算

```
ICEスコア = (Impact + Confidence + Ease) / 3
```

各項目は 1〜10 の整数で入力。スコアが高いほどリストの上位に表示。

### インラインヘルプ（ツールチップ）

主要な用語（ICEスコア・Impact・Confidence・Ease・Conversion率・ファネル等）に「?」アイコンを設置。クリックで説明ポップアップを表示。

## 7. ポータルリファレンスページ設計（`/guide`）

知識ゼロのメンバーがポータル全体の使い方・各機能の目的・グロースハック手法を学べる読み物ページ。ポータルのカードとして全ロール（外部除く）に公開。

### セクション構成

1. **ポータルの使い方** — 各ダッシュボードへのアクセス方法・ロールについて
2. **グロースハックとは** — 概念・考え方・なぜ導入するか
3. **ファネルの読み方** — 各ステップの意味・ボトルネックの見つけ方
4. **ICEスコアの使い方** — Impact / Confidence / Ease の定義・採点基準・例
5. **良い施策の書き方** — 具体的な施策の条件・テンプレート・実例
6. **各ダッシュボードガイド** — 売上・広告・Pamun・Trepo それぞれの読み方
