# Trepoトレンド大賞2026 エントリーフォーム 項目確定版

- 作成日: 2026-06-16
- 親設計書: `2026-06-16-trepo-trend-award-selection-design.md`
- 目的: フォーム項目を確定し、候補プールDB（Notion）のプロパティと1対1対応させる。
- 方針反映: 実績型に純化（予兆型の条件c削除）／実績欄をスコアカードのエビデンス必須要件に直結。

---

## エントリー条件（実績型に確定）

```
■該当するエントリー条件（いずれかに該当・ラジオ選択）
 a. 2026年上半期に売れた・話題になった商品・サービス・スポット・コンテンツである
 b. 2026年下半期に売れている・話題になっている商品・サービス・スポット・コンテンツである
 ※「来年以降に売っていきたい」等の未来予測のみの対象は対象外です
```

> 旧条件 c（「a・bに該当しないがエントリーしたい強い理由がある」）は削除（実績型に純化）。

---

## フォーム項目（確定版）

### 0. フォーム説明
社内企画メモの注意事項文を流用。以下を明記する。
- エントリー費: 無料
- エントリー締切: 2026年7月15日（水）23:59
- エントリー上限: 1社につき3件まで（正規販売店・PR代理店は除く）
- 1対象につき1フォーム／部門は1対象につき2部門まで
- 予選あり・対象外条件（医薬品/医療行為/サロン・クリニック専売/体験のみ完結 等）

### 1. 企業情報
- 会社名【必須】
- クライアント様名（※正規販売店様・PR会社様はご記入ください）【任意】
- 部署名【必須】
- 担当者名【必須】
- メールアドレス【必須】
- 電話番号【必須】
- コーポレートサイトURL【必須】

### 2. エントリー情報
- エントリー対象名【必須】
- 該当するエントリー条件（a / b のラジオ）【必須】
- カテゴリ（select）【必須】
  - コスメ / スキンケア / ヘアケア / ボディケア / フレグランス / 食品・飲料 /
    ライフスタイル雑貨 / ファッション / おでかけ・スポット / エンタメ・コンテンツ / その他
- 発売日／開始日【必須】
- 商品URLまたはサービスURL【必須】
- 価格【必須】
- 商品・サービス概要【必須】
- ターゲット層【必須】
- 2026年らしいトレンドポイント【必須】
- 実績・反響（複数選択）【必須】
  - SNSで話題 / 売上好調 / メディア掲載あり / 店頭反響あり / インフルエンサー反響あり / その他
- 実績詳細記入欄【必須】
  - 説明文（スコアカード連携・エビデンス促進）:
    ```
    実績を裏付ける具体的な根拠（SNSの反響数・売上やランキング・掲載メディアのURL等）を
    できるだけ数値やリンクでご記入ください。選定の参考にいたします。
    ```
- 画像添付または画像DLリンク【必須】
- サンプル提供可否【必須】
- 個人情報取扱への同意（必須チェック）【必須】

## 削除した項目

- 「Trepoトレンド大賞2026にエントリーしたい理由」
  - 理由: 条件a/b＋実績欄で代替できるため（社内企画メモでも「要らないかも？」と注記あり）。

## 候補プールDBとの対応（突合用）

| フォーム項目 | 候補プールDBプロパティ |
|---|---|
| エントリー対象名 | 対象名（title） |
| （フォーム経由のため自動） | 流入経路 = インバウンド |
| カテゴリ | カテゴリ（select） |
| 該当するエントリー条件 | エントリー条件（select a/b） |
| 会社名・担当者・連絡先 | 企業名 / 担当者・連絡先 |
| 商品URL | 商品/サービスURL |
| 価格 | 価格 |
| 概要 | 概要 |
| トレンドポイント | トレンドポイント |
| 実績・反響＋実績詳細 | 実績スコア各項目の根拠素材（SNS/売上/メディア/検索/インフル） |
| サンプル提供可否 | （審査運用で参照） |
