# Trepoトレンド大賞2026 各審査段階チェックリスト

- 作成日: 2026-06-16
- 親設計書: `2026-06-16-trepo-trend-award-selection-design.md`（§3.1 / §3.3 / §3.4）

## 0次：形式要件チェック（〜8/31）

候補プールに入った全対象に対して実施。

```
□ 対象外カテゴリでないか
   （医薬品 / 医療行為を伴うもの / サロン・クリニック専売品 / 体験のみで完結するサービス）
□ 掲載が難しい表現を含まないか
□ Trepo読者層（Z世代女性）との親和性が著しく低くないか
□ 極端に高額で、一般読者にとって非現実的でないか
→ すべてクリア = 「形式要件 = OK」
→ 1つでも該当 = 「対象外」
```

## 1次：スコアカード審査（〜9月中旬）

形式要件OKの対象に対して実施。

```
□ 2〜3名の編集者で採点したか
□ 実績点に根拠（リンク/数値/スクショ）を添付したか（エビデンス必須）
□ 根拠が空の実績点はないか（あれば採点やり直し）
□ 該当しない実績項目はN/A（空欄）にしたか
□ 採点者間で平均をとり、総合スコア（実績×0.5＋編集×0.5）を算出したか
□ カテゴリ別ランキング上位をノミネート確定したか
```

## 2次：Trepoガールズお試し会（9/28・29）

ノミネート確定対象に対して実施。

```
□ Trepoガールズが実際に体験したか
□ 読者評価を「当事者検証レイヤー」として記録したか
   （※1次スコアには混ぜず、お試し会評価として別記録）
```

---

## 3次：審査員による最終審査（10月上旬）

```
□ 1次総合スコア・お試し会評価・審査員評を統合したか
□ カテゴリ賞・注目賞・最上位賞の順位（1〜3位）を確定したか
□ 大賞（最上位賞・1位のみ）を決定したか
```

### 確定版 受賞部門（判定対象）

```
【最上位賞（1位のみ）】 Trepoトレンド大賞2026
【注目賞（1〜3位）】   Z世代注目大賞 / ベストSNS話題賞
【カテゴリ賞（1〜3位）】 ベストスキンケア賞 / ベストコスメ賞 /

                        ベストエンタメ賞 / ベストコラボ賞 / ベスト新商品賞
```
