# Trepoトレンド大賞2026 スコアカード採点シート 構成仕様

- 作成日: 2026-06-16
- 親設計書: `2026-06-16-trepo-trend-award-selection-design.md`（§3.2 / §3.4）
- 目的: 複数編集者（2〜3名）による採点 → 平均、という運用を支えるシート。候補プールDB（Notion）の単一スコアでは扱えない「採点者ごとの記録と平均化」を担う。
- 推奨ツール: スプレッドシート（Googleスプレッドシート）

---

## シート構成

### タブ1: 採点入力（1候補 = 1ブロック）

各候補ブロックに、採点者2〜3名分の列を用意する。

```
候補名: ___________________  カテゴリ: __________

                          採点者A      採点者B      採点者C
── 実績スコア（1-5, 根拠必須） ──
SNS話題量      点 / 根拠     [ ]/[URL]   [ ]/[URL]   [ ]/[URL]
売上実績       点 / 根拠     [ ]/[URL]   ...
メディア掲載   点 / 根拠     [ ]/[URL]
検索の伸び     点 / 根拠     [ ]/[URL]
インフル反響   点 / 根拠     [ ]/[URL]
  → 実績スコア(採点者別) = 該当項目のみ正規化 (sum/count*20)

── 編集評価スコア（1-5, 一言コメント必須） ──
今年らしさ     点 / コメント
Z世代親和性    点 / コメント
ストーリー性   点 / コメント
推し度         点 / コメント
  → 編集評価スコア(採点者別) = 合計/20*100
```

### 集計行（採点者間で平均）

```
実績スコア(平均)   = AVERAGE(採点者A実績, B実績, C実績)
編集評価スコア(平均) = AVERAGE(採点者A編集, B編集, C編集)
総合スコア          = 実績スコア(平均) × 0.5 + 編集評価スコア(平均) × 0.5
```

### タブ2: カテゴリ別ランキング

- 全候補の「総合スコア」をカテゴリ別に降順ソート。
- 各カテゴリの上位N件をノミネート確定の判断材料とする。

---

## エビデンス必須ルール（シート冒頭に明記）

```
【採点ルール】
・実績5項目は、点数を入れたら必ず根拠（リンク/数値/スクショ）を記入すること。
・根拠が空欄の点数は無効とし、採点をやり直す。
・該当しない実績項目は空欄（N/A）とし、集計から除外する（残りの該当項目のみで正規化）。
・編集評価4項目は、各点数に一言コメントを添える。
```

---

## 計算式の整合（設計書 §3.2 と一致）

- 実績スコア = (該当項目の合計 ÷ 該当項目数) × 20 ＝ 100点換算
- 編集評価スコア = (合計 ÷ 20) × 100 ＝ 100点換算
- 総合スコア = 実績 × 0.5 + 編集 × 0.5（重み50:50）

> 候補プールDB（Notion）は「代表値（合議後の確定スコア）」を保持し、本シートは「採点者ごとの記録と平均化」を担う、という役割分担。
