## 記録ルール

候補を見つけたら、**候補プールDB（Notion）** に登録する。

```
1. 新規レコードを作成し「流入経路 = 編集部リサーチ」を選択
2. 必須項目を埋める: 対象名 / カテゴリ / 商品・サービスURL
3. その場で実績スコア素材を可能な範囲で記録:
   - 各実績項目の点数（1-5）+ 根拠（リンク/数値/スクショ）
   - 根拠なしの点数は入れない（エビデンス必須）
   - 当てはまらない項目は空欄（N/A）のまま
4. 気づいた「トレンドポイント」をメモ欄に残す
```

> ポイント: 記録フォーマット（＝候補プールDBの実績項目）は、そのままスコアカードの採点素材になる。観測しながら採点素材が貯まる設計。

## 役割分担と頻度

- 観測カテゴリを編集部内で分担する（例）:
  - 美容班: コスメ / スキンケア / ヘアケア / ボディケア / フレグランス
  - 食品・生活班: 食品・飲料 / ライフスタイル雑貨
  - カルチャー班: ファッション / おでかけ・スポット / エンタメ・コンテンツ
- **週次**で候補プールDBをレビューし、重複排除・候補の取捨を行う。
- インバウンド（フォーム応募）も同じDBに合流するため、週次レビューで併せて確認する。

## オファー対象への企業連絡（候補確定後）

- ノミネート候補に挙がった対象の企業へ連絡し、商品サンプル・画像素材・関連資料の提供を依頼。
- タイミング: スケジュール（仮）の「企業連絡＆商品取寄せ 9/11〜9/25」と整合。
